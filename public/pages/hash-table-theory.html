3. Resizing and Rehashing

Hash function used in this simulation

To keep the simulation easy to follow, keys are integers and the hash is intentionally simple: hashKey(k) = (k >>> 0) (conversion to an unsigned 32-bit integer).

The start slot is then computed as startIndex = hashKey(k) mod capacity. If the start slot is occupied by a different key, we use linear probing: check the next slot, then the next, wrapping around.

Note: real hash tables use much stronger hashing (bit mixing) especially for non-integer keys (strings, objects). Here the goal is to clearly show the role of mod capacity, collisions and probing, and why a resize requires a rehash.
