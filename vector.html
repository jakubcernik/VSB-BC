Best Case

The Best Case scenario occurs when the array still has unused capacity. Inserting a new element is instant because no resizing or copying is needed.

Complexity: O(1)

Worst Case

The Worst Case scenario occurs when the array is completely full. Inserting a new element forces a resize—allocating a larger array, copying all elements, and then inserting.

Complexity: O(N)
